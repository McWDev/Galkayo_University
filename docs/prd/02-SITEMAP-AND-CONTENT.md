## Content model fields
### Standard page
Title, slug, summary, body, featured image, SEO title, SEO description, status, author, reviewer, published date, updated date, review date.

### Faculty
Name, slug, overview, dean/contact details (if approved), departments, programmes, image, campus/location, status, SEO fields.

### Department
Name, slug, faculty relation, overview, programmes, approved contact details, status, SEO fields.

### Programme
Name, slug, faculty/department relation, award/qualification, level, duration, study mode, overview, entry requirements, required documents, tuition/fee note (optional, approved only), application instructions/link, status, last reviewed date, SEO fields.

### News article
Title, slug, summary, body, category, author/byline, featured image, attachments, status, publication date, SEO fields.

### Event
Title, slug, summary, description, start/end date, venue, registration link (optional), image, status, contact, SEO fields.

### Public document
Title, category, description, file URL, file type, file size, publication date, version, status, expiry/review date, copyright/usage note.

### Research item
Title, authors, abstract/summary, publication type, journal/conference, publication date, DOI/URL (optional), attachment or repository URL, keywords, rights statement.

## Content migration
- Copy only content GU has permission to publish.
- Do not copy Salaam University text, images, or branding.
- Create a content inventory spreadsheet/document before launch.
- Label all unverified content as a draft in the CMS; never display it publicly.
- Redirect old GU URLs where relevant and possible.
