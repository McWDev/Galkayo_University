# UI and Brand Guide — Galkayo University

## Brand reference
Use the supplied Galkayo University logo as the primary identity reference. The visible logo uses:
- Deep/dark green for the main GU lettering and outlines
- Gold/yellow for the circular border and accents
- White/light backgrounds
- Green Arabic/Somali lettering and dark text details

These are visual estimates from the supplied raster logo. Before implementation, sample the original high-resolution brand asset and ask GU to confirm official brand values.

## Provisional tokens
- Primary green: `#064B2F` (provisional; sample/confirm against source logo)
- Deep green: `#033B27`
- Gold accent: `#E5BD00` (provisional)
- White: `#FFFFFF`
- Page background: `#F8FAF8`
- Main text: `#18231D`
- Muted text: `#5D6A62`
- Border: `#DCE4DE`
- Error: accessible dark red selected after contrast testing

Do not rely on color alone to communicate status. Check text/background contrast.

## Design direction
- Modern, professional, academic, trustworthy
- Spacious layouts and clear hierarchy
- Use green for primary actions and key identity
- Use gold sparingly for highlights, active indicators, or thin borders
- Prefer real GU campus, staff, students, labs, library, and event photography with permission
- Avoid stock images that could misrepresent GU
- Keep headings, cards, and buttons consistent across pages
- Mobile navigation must be easy to use with keyboard and touch
- Do not distort, recolor, or crop the university logo in ways that damage its identity

## Components
Header, mobile navigation, footer, breadcrumb, hero, CTA, statistic tile, faculty/programme card, news card, event card, document row, search/filter, pagination, alert banner, form fields, confirmation message, admin table, status chip, empty state, loading state, error state.

## Accessibility
- Semantic heading hierarchy
- Visible focus indicators
- Keyboard-operable menus and dialogs
- Accessible form labels and error summaries
- Descriptive alt text for meaningful images; empty alt for decorative images
- Respect reduced-motion preference
- Ensure responsive zoom and readable type sizes
